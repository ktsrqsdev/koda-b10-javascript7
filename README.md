## Callback dan setTimeout

Program JavaScript ini menampilkan angka 0 hingga 4 secara berurutan dengan jeda 1 detik menggunakan `setTimeout()` dan callback. Setiap fungsi memanggil fungsi berikutnya melalui callback, sehingga program ini menunjukkan konsep **asynchronous JavaScript** dan penggunaan callback bertingkat (*callback nesting*).
